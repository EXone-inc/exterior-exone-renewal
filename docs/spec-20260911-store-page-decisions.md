## 決定済み方針（再掲・仕様書本文と同じ）

- カンプは PC（1920）のみ。SP は既存ページの流儀で暫定補間
- 固定ページ + `page-store` テンプレート + `inc/store-data.php`。URL は `/store/<slug>/`（sendai / totsuka / morioka / aomori / hachinohe / hirosaki / tokyo）
- 共通ヘッダー（RECRUIT 込み 7 項目）・共通フッターをそのまま使う
- WORKS / COLUMN は既存 CPT（works / news）の最新をそのまま表示
- 画像は Figma から取得済みのものを `images/store/` に取り込んで先に組み、高解像度版は後で同名差し替え
- REVIERS → REVIEWS、「完成・お引き渡し」に統一。669:208「タイトル名」・hidden・キャンバス外ノードは実装対象外
