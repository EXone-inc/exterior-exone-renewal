# お知らせ（一覧・詳細）ページ — 決定事項

- 作成: 2026-10-14
- カンプ: **無し**。デザイン・構成の正は**コラムページ**（`/column/` 一覧 `archive-column.php` / `/column/<slug>/` 詳細 `single-column.php`、`css/column-page.css`）。コラムの決定事項は `docs/spec-20261010-column-page-decisions.md`
- 本ファイルは、ユーザーの指示・回答と、それを受けて呼び出し側が決めた既定をまとめたもの。仕様書（`docs/spec-20261014-news-page.md`）と食い違う場合は**本ファイルが正**

## 1. ユーザーの指示（2026-10-14）

- 「コラムページと同様なデザインでお知らせページを作成してください。カテゴリーの部分は、年月で絞り込みできるようにしたい。例えば、『2026年5月』など。」

## 2. ユーザーの回答（2026-10-14。すべて推奨どおり）

| 質問 | 回答（= 推奨） |
|---|---|
| 年月タブの並び | **投稿がある年月だけ**。「すべて」の後に、公開済みのお知らせが 1 件以上ある年月を新しい順に並べる（ラベル「2026年5月」）。空の月は出さない |
| 絞り込み後の URL | **`/news/?ym=2026-05`**（コラムの `?cat=` と同じ作り。ページ送りは `/news/page/2/?ym=2026-05`。支店モード `?store=` と併用可） |
| コラムでカテゴリーのチップがある位置 | **何も出さない**（日付に年月が含まれ重複するため。カード・詳細とも日付とタイトルだけ。カードは抜粋あり） |
| 本文の入力 | **いまの「説明」のまま**（投稿画面は変えない。テキストエリア → `post_content` にプレーンテキスト） |

### 2 回目（planner の要確認を受けて。2026-10-14）

| 質問 | 回答 |
|---|---|
| 正しい形式だが 0 件の年月（`?ym=2026-03` など） | **0 件のメッセージを出す**（タブは出すがどれも選択中にしない） |
| 年月タブが増えたとき | **全部出して折り返す**（コラムのタブと同じ見た目） |
| 詳細ページ | **不要**（ユーザー指示「お知らせ詳細ページは不要です」）。`/news/<slug>/` は一覧へ 301 転送 |
| 一覧の各お知らせの内容 | **日付・タイトル・説明文を全文**。押せないカード。画像があればサムネイルも出す（コラムのカードと同じ見た目） |
| TOP のお知らせカードのリンク | **一覧 `/news/` へ**（支店モードは `?store=` 付き） |
| 説明文内の URL | リンクにしない（詳細ページが無くなったため聞いていない。既定） |
| 詳細末尾の COLUMN セクション | 対象外（詳細ページが無い） |

## 3. 既定（呼び出し側が決めた。変えたい場合はユーザーに確認）

- 投稿タイプは既存の `news`（`inc/post-types.php`。`has_archive` で `/news/`、個別 `/news/<slug>/`）をそのまま使う。CPT・メタボックス（「説明」「画像」）は変更しない
- TOP のお知らせセクション（`template-parts/top/section-news.php`）は変更しない。VIEW MORE は既に `/news/` に向いている
- 既存のダミー 6 件（2026-08）は仮データとして残す。年月タブの検証用に、別の月の【仮】お知らせを WP-CLI で追加してよい（本番の内容は後から入れる。公開前に仮データを削除）
- 不正な `ym`（形式違い・該当月なし）の扱い、CSS の共有方法、データ関数の置き場、文言（絞り込み見出し・0 件時・戻るリンク）は仕様書の推奨に従う。コラム側の表示は変えない
- ヘッダーはコラムと同じ扱い（コーポレートでは半透明グラデのオーバーレイヘッダー + ヘッダー分の余白。支店モードでは支店ヘッダー）

### 呼び出し側の補足判断

- **AC-05-7「コラムページの差分 0」の判定基準**（S1 評価で指摘）: `docs/baseline-20261014-news/compare.py` は 1 画素あたり色差 40 までを同一とみなす。写真の縮小による揺らぎを吸収するための閾値なので、**この閾値での「changed 0」+ 4 URL の HTML の diff 0 行 + `css/column-page.css` の変更がコラムの表示に影響しないことのレビュー**、の 3 つが揃えば合格とする（閾値 0 の厳密一致は求めない）。HTML diff は `column-page.css?ver=` の行と、S5 で意図して変えるメニュー・フッターの「お知らせ」の href（`#` → `/news/`）を除いて 0 行であればよい（S5 generator の指摘を受けて 2026-10-14 に補足）

### 進捗

- S1（検証用データ・コラムのベースライン）: 2026-10-14 合格
- S2（一覧 `/news/`）: 2026-10-14 合格。CSS はコラムの `column-page.css` とクラス名を共有（`.is-news-page` のセレクタ追加・ホバーを `a.p-colp__link` に限定）、差分は `css/news-page.css`。説明文の段落間隔 `--news-para-gap: 1em` は generator の判断（カンプ無し）
