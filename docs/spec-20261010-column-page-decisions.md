## 3. 既定（呼び出し側が決めた。変えたい場合はユーザーに確認）

### データ
- 投稿タイプ `column`（表示名「コラム」。`has_archive` でアーカイブ `/column/`、個別 `/column/<slug>/`）とタクソノミー `column_category`（「コラムカテゴリー」。階層なし）を **現サイトと同じ名前**で `inc/post-types.php` に登録（CPT UI は使わない）。現サイトの記事は WordPress の書き出し／取り込みでそのまま移せる
- 記事の項目は WordPress 標準: タイトル・本文（ブロックエディタ。現サイトは「カスタム HTML」ブロックに HTML を貼っている）・抜粋（任意）・アイキャッチ・カテゴリー。独自のメタボックスは追加しない
- 一覧の抜粋: 抜粋があればそれ、無ければ本文からタグ・コメントを除いて 90 文字 + 「…」（現サイトと同じ）
- 仮データ: カテゴリー 5 つ + 仮記事 12 件（現サイトの 10 記事のタイトルを使い、本文は 1 件だけ `prod-detail-body.html` の HTML、他は短いダミー。アイキャッチは現サイトの画像を使わず、テーマ内の既存写真（`images/works/` 等）を `media import` で登録して割り当てる）。ページ送りを確認できるよう 12 件（10 件/ページ）

### 一覧 `/column/`（`archive-column.php`）
- 構成: 見出し「COLUMN」（英字。他ページの FV 見出しと同じ書体）+「外構・エクステリアのお役立ち情報コラム」→「カテゴリーで絞り込む」+ タブ（すべて + カテゴリー）→ 記事カード（サムネイル／投稿日 `YYYY.MM.DD`／カテゴリー／タイトル／抜粋。カード全体がリンク）10 件 → ページ送り（前へ・番号・次へ）→ フッター
- **FV（写真帯）は置かない**（現サイト・Figma の参考画像とも無い）。見出しは白地の上
- 絞り込みはサーバー側（現サイトと同じ `?cat=<slug>`。ページ送りは `/column/page/2/?cat=…`）。`cat` は WordPress 予約のクエリ変数なので、衝突するなら `column_cat` にしてもよい（その場合は現サイトからの URL 互換は不要。報告する）
- 0 件のとき（カテゴリーに記事が無い）: 「該当する記事はありません」（WORKS と同じ文言の型）
- 支店モード `?store=`: ヘッダー・フッターの出し分けと内部リンクの `?store=` 引き継ぎ（`exterior_exone_store_link()`）のみ。カード・タブのリンクにも付ける
- レイアウトは現サイトの一覧（`column.css` の `.c_gallery_*`: サムネ左・文字右の横並びカード、PC 幅 1400 内）を新サイトのトークンで組み直す。SP は 1 カラム（サムネ上・文字下）。トークンは `--col-*` の比例ブロック（`--col-vu` / `--col-su`、他ページと同じ作法）

### 詳細 `/column/<slug>/`（`single-column.php`）
- 構成: カテゴリー + 投稿日（更新日が投稿日と違えば「最終更新日」も）→ タイトル（h1）→ アイキャッチ → 本文 → 前の記事／次の記事 → 「コラム一覧へ戻る」→ COLUMN セクション（共通部品 `template-parts/common/section-column.php`。最新 3 件、表示中の記事は除く）→ フッター
- 本文の幅 1400（コンテンツ 1600 の内側）。見出し h2 / h3、段落、画像、リスト、表の基本スタイルを新サイトのトークンで（`column_detail.css` の値を参考に、文字サイズは他ページに合わせる）
- **本文内の部品のクラス名は現サイトと同じ**にしてスタイルを用意する（`prod-detail-body.html` に実例あり）: `.exone-col`（本文ラッパ）、`.summary`（目次 `.toc` を含む要約ボックス）、`.box` / `.box-ttl`、`.check`（チェックリスト）、`.tbl` / `.tbl-wrap`（表）、`.img-grid2`、`.faq-a`、`.cta` / `.btn-main`（本文内 CTA）、`.author`（この記事を書いた人）、`.note`、`.accent`、`.lead`、`.head`、`.label`、`.mk`、`.name`、`.s` / `.t`、`.eyebrow`、`.logo`、`.desc`。配色は指示書きの反転ルール（現サイトの黒地 → 白地）
- 本文内の画像は現サイトの URL のまま（仮記事のみ。本番は取り込み時に移る）
- 前の記事／次の記事は公開日順。無い側は出さない

### 共通
- CSS は `css/column.css`（一覧・詳細・本文部品をまとめて 1 本。`is_post_type_archive('column') || is_singular('column')` のときだけ読む）。トークンは `:root` に `--col-*`、色はすべて既存トークン（white4 / black2 / black1 / orange1 / gray2）
- ヘッダー・ドロワー・フッターの「コラム」（`inc/menus.php` の `#`）→ `get_post_type_archive_link('column')`（支店モードは `?store=` 付き）
- 支店ページ・WORKS ページ・詳細末尾の COLUMN セクション: いまの `exterior_exone_news_cards()`（お知らせの仮）を **コラムの最新 3 件**に差し替える（`exterior_exone_column_cards()`）。カードの見た目は変えない。コラムが 0 件ならセクションごと出さない
- 日付の書式 `Y.m.d`。英字見出し・和文見出しは他ページの型（`c-store-title` 等の共通クラスがあればそれ）

### 対象外
- タブレット専用の組み（1024/1025 の切り替えのみ）、記事の検索、タグ、著者ページ、SNS シェアボタン、現サイトからの記事の実移行（手順は公開前チェックリストに書く）
