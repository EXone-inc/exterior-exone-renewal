## 1. 到達点と対象外

到達点は、現在の本番サイトが旧テーマで動いたまま、PHP 7.4 向けに検証した別テーマのファイルが追加され、テーマ一覧で未有効として確認できる状態である。バックアップ取得とこの範囲の導入はユーザー承認済みとして進め、同じ承認を再度求めない。最新承認により、**既存データ・設定を書き換えず未有効テーマを新規追加する今回に限り、Web 全体の PC 保存完了を必須条件から外す**。未完了の保存を完了扱いにはしない。

**テーマが選択肢に現れても、新テーマへの切り替え準備がすべて完了したことにはならない。** 新旧の内容分離、インポーター、データ追加、本番コラムの SEO 出力・プラグイン互換性、切り替えと復帰の総合検証は別段階である。本段階の報告から、手動切り替えが安全に実施できるとの意味を生じさせない。

今回、以下は行わない。

## 4. 順序と停止条件

非公開コピーでの準備・監査・PHP 7.4 検証は、バックアップ取得と独立して進められる。**本番アップロードは、最新承認に基づく AC-01 の復旧経路確認と AC-02〜06 の確認後**に行う。Web 全体の PC ダウンロードを再開することは前提にしない。導入後は AC-08〜10 で結果を確定する。

アップロード後に旧サイトの差異が見つかった場合は、さらに設定を変更せず、追加した専用フォルダーとの関係を調べる。通常の復旧は、その未有効の追加フォルダーだけを manifest と照合して除去し、旧サイトを再確認する。旧テーマへ切り替える操作は不要である。関係のない既存ファイルや未確認のファイルを削除しない。
