## 1. 背景・目的

支店ページ（`/store/<slug>/`、6 拠点）は地域の見込み客の入口になる。今は支店ページもコーポレートと同じヘッダー・フッターで、支店から DX・PLANS・WORKS に進むと「どの支店のサイトにいるか」が失われる。支店から入った人には支店サイトとしての一貫したヘッダー・フッター（支店名入り・支店向けメニュー）を見せ続け、「コーポレートサイト」を押したときだけコーポレートに戻す。コーポレート側の見た目と動きは変えない（WORKS / 事例一覧のリンク先を除く）。

## 2. スコープ

### やること
- 支店モードの判定（支店ページ表示中 / `?store=<有効な slug>`）
- 支店モード中のサイト内リンクへの `?store=<slug>` 引き継ぎ（テーマが出力するリンクすべて。例外は §4.3）
- 支店用メニュー（PC ヘッダー 5 項目 / フッター MENU 8 項目 / SP メニュー MENU 7 項目）と、ロゴ・「○○支店」の出力と行き先
- WORKS / 事例一覧のリンク先を `#` → `/works/` に変更（コーポレート・支店とも）
- 支店用 PC ヘッダーの見た目（113px・#000000・支店名・オレンジの CONTACT ボタン）と SP の支店名
- 支店モードの PLANS ページ（PC のみ）でのタブ位置
- ヘッダー高さが変わることによる各ページの崩れの確認と手当て
- 旧カンプ nodeId のコメント更新、`CLAUDE.md` フレーム対応表への追記

### やらないこと（範囲外）
- コーポレート用ヘッダー・フッターの見た目の変更（決定 §6）
- 決定 §7 の細部（線の色 #4d4d4d / #454545、SP メニュー見出し・リンク色、SP「TOP」14px、「Face book」表記）
- `/works/`・`/news/` のページの中身（`index.php` の素の一覧のまま）
- CONTACT / お問い合わせ・お知らせ・コラム・RECRUIT・SNS のリンク先（`#` のまま）
- 東京オフィスの復活（STORE 列は 6 拠点のまま。決定 §5 フッター）
- SP の閉じるボタンの変更（× のまま）、SP のプランナビ、SP ヘッダーの CONTACT
- 現在地表示（今いるページ・今いる支店の強調）
- 管理画面のメニュー割り当て（現状どおり未割り当てで運用。§6 Q1）
- ページキャッシュの設定（公開前チェックリスト扱い）

### F-01: 支店モードの判定と body クラス

- 概要: 表示中のリクエストが「支店モード」かどうかと、その支店（slug・支店名）を 1 か所で判定できるようにする。支店モードのときだけ `<body>` に `is-store-mode` クラスを付ける。
  - 支店モード = (1) 支店ページ `/store/<slug>/` を表示中、または (2) `$_GET['store']` を `sanitize_key()` した値が支店キーのどれかと一致
  - (1) と (2) が食い違うとき（`/store/sendai/?store=aomori`）は (1) を優先
  - `?store=` が不正（存在しない slug・空・配列など）ならコーポレート。PHP の Notice / Warning を出さない
  - `store` を WordPress の公開クエリ変数として**登録しない**。`home_url` フィルタも使わない（決定 §3・§4）
  - 既存の `exterior_exone_current_store()` / `exterior_exone_is_store_page()` の意味（固定ページのスラッグで判定）は変えない。テンプレート振り分け・`is-store-page`・支店ページ内のセクションがこれに依存しているため。支店モード判定は別の関数として足す（名前は `exterior_exone_` 接頭辞で Generator が決める）
  - 支店一覧 `/store/` は `?store=` が無ければコーポレート、有効な `?store=` があれば支店モード
- Figma ノード: なし（ロジック）
- ユーザーストーリー: 支店ページから来た見込み客として、どのページへ進んでも同じ支店のサイトにいる状態でいたい。なぜなら地元の支店に相談したいから。
- 受け入れ基準:
  - [ ] AC-01-1: `/store/aomori/` の `<body>` に `is-store-mode` と既存の `is-store-page` の両方が付く
  - [ ] AC-01-2: `/dx/?store=aomori`・`/plans/?store=aomori`・`/works/?store=aomori`・`/dx/vr/?store=aomori`・`/company/?store=aomori`・`/store/?store=aomori` の `<body>` に `is-store-mode` が付き、`is-store-page` は付かない
  - [ ] AC-01-3: `/`・`/dx/`・`/plans/`・`/works/`・`/company/`・`/dx/vr/`・`/store/` の `<body>` に `is-store-mode` が付かない
  - [ ] AC-01-4: `/dx/?store=xxx`・`/dx/?store=`・`/dx/?store[]=aomori`・`/dx/?store=tokyo` はコーポレート表示（`is-store-mode` なし、PC ヘッダーのメニューが F-05 のコーポレート 7 項目）。HTTP 200
  - [ ] AC-01-5: `/dx/?store=AOMORI` は `sanitize_key()` で小文字化されて青森支店の支店モードになる
  - [ ] AC-01-6: `/?store=aomori` は HTTP 200 で TOP（フロントページ）の内容が表示され（FV セクションが存在し、投稿一覧にならない）、`is-front-page` と `is-store-mode` の両方が付く
  - [ ] AC-01-7: `/store/sendai/?store=aomori` は仙台支店の支店モード（ヘッダーの支店名が「仙台支店」）

### F-02: サイト内リンクへの `?store=` 引き継ぎ（共通ヘルパーと置き換え）

- 概要: 「URL を受け取り、支店モードなら `?store=<slug>` を付けて返す（コーポレートならそのまま返す）」共通ヘルパーを 1 つ用意し、テーマが出力する内部リンクをこれ経由にする。
  - 対象（現状の出典。漏れがあれば同様に扱う）: `inc/menus.php` の `home_url()` 7 か所 / `header.php` 2 / `footer.php` 1 / `inc/dx-data.php` 1（VR 展示場 `/dx/vr/`）/ `template-parts/top/section-dx.php` 1 / `get_permalink`（`inc/top-data.php` の WORKS・NEWS カード）/ `get_post_type_archive_link`（`template-parts/top/section-news.php`・`top/section-works.php`・`store/section-column.php`）/ `the_permalink`（`index.php`）
  - 既にクエリがある URL には `&store=` で足す。フラグメント（`#...`）は維持してその前に入れる。同じ `store` が既にあれば二重に付けない
  - 例外（付けない。決定 §4）: 「コーポレートサイト」（`/`）/ 支店ページ `/store/<slug>/` そのもの / 外部リンク（LINE・`tel:`・`https://www.exone-package.com/`・SNS）/ `#` だけの未設定リンク / ページ内リンク（`#package` など）
  - 出力時のエスケープは既存どおり `esc_url()`（`&` が `&#038;` になるのは可）
  - `<link rel="canonical">`・REST・フィード・`wp_head` 内の URL には付けない
- Figma ノード: なし
- ユーザーストーリー: 支店サイトを見ている見込み客として、本文中のボタンやカードを押しても支店サイトのままでいたい。なぜなら途中でコーポレートに飛ばされると迷うから。
- 受け入れ基準:
  - [ ] AC-02-1: `/dx/?store=aomori` の DX ページ内「VR 展示場」へのボタン（ステップ 01）の href が `/dx/vr/?store=aomori`

  - [ ] AC-02-3: `/store/aomori/` の COLUMN セクションのカード（記事があれば）と「VIEW MORE」の href に `?store=aomori` が付く

  - [ ] AC-02-5: `/store/aomori/` の CTA の LINE・電話リンク、`/plans/?store=aomori` のパッケージプラン「VIEW MORE」（`https://www.exone-package.com/`）、SNS リンク、`#` のリンクに `store=` が付かない

  - [ ] AC-02-8: コーポレート（`/`・`/dx/`・`/store/aomori/` 以外のクエリ無しページ）の HTML に、テーマが出力した `store=` を含む href が 1 つも無い（`grep -c 'store='` が 0。ただし支店ページ `/store/<slug>/` へのパス自体は対象外）
