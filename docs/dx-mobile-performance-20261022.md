# DX Experience の SP 描画負荷軽減（2026-10-22）

## 依頼と範囲

Android の SP 表示で、とくに 02→03 が重い。ユーザー承認によりローカル・本番へ次を適用する。

- 1024px 以下の03はリアルタイム3Dから事前描画した回転動画へ変更。
- 同じ幅の02は線の個別発光・写真のぼかしを外し、線画と透明度の切り替えを残す。
- PHPバージョン、DB、テーマ選択は変更しない。バックアップ不要の指定を継続。

## 調査根拠

本番のJS/CSS・02画像・03GLBがローカルと同一であることをハッシュで確認。
02は1033×748のWebP2枚、計207,352bytes。容量より64形状それぞれの3重drop-shadowとblur10pxが候補。
03は4,790,300bytes、327,645三角形・123テクスチャで、RGBA展開だけで概算105MiB。
02停止時のクラス除去に伴うフェード/ぼかしと、03開始時の回転が、0.9秒の横移動に重なる構造だった。
Android実機での性能トレースは未取得。

## 実装

- inc/dx-data.php / template-parts/dx/section-steps.php: SP映像・ポスターURLを追加。
- js/dx-bimx.js: SP初期表示ではmodel-viewerもGLBも読み込まない。工程に近づいたら映像を準備し、03入場完了・可視・タブ表示中だけ再生。動きを減らす設定はポスターのみ。自動再生拒否はユーザー操作で再試行。エラーは既存画像へ戻す。
- PCは3Dを維持。幅変更中の非同期読み込みを世代番号で隔離し、古いロード結果が新しい表示を壊さないようにする。
- js/dx-ai-pers.js: SP退場時は線画を一時停止し、完成写真のフェードを再発させない。次回入場でリセット。タブ非表示も停止。
- css/dx.css: SPの線のdrop-shadowと写真blurを省き、背景写真のbrightnessを一定にする。PC演出は従来どおり。
- js/dx-steps.js: 動きを減らす設定ではis-movingを付けず、設定変更によってtransitionendが来なくなった場合にも待機状態を解除。

## 03 のタップ待ち改善（同日）

ユーザーから「タップ前から回転動画を表示したい」との依頼。dx-bimx.js で muted/defaultMuted と playsinline 属性を明示し、03の可視・入場完了時に autoplay を有効化。loadeddata、pageshow、ページ内の通常のタッチ操作でも再生を再試行する。非表示時は autoplay を解除して停止。再生開始前は動画と同じ配置の独立したポスター画像を表示し、playing イベントで隠す。動きを減らす設定はポスター表示を維持する。

ローカル390pxでタップなしの自動再生、ポスターと動画の幅455.21px一致、02での停止を確認。実JSのDOM/media模擬検査41項目、JS構文、diff空白検査通過。CSS/JSの2ファイルを本番へ反映し、ハッシュ一致と作業ステージ削除を確認。配信記録: dx-mobile-autoplay-20261022。動画ファイル、PHP、DBは変更なし。実Android/iPhone端末の検証は未実施。

## PC 02 の演出統一と SP 03 の再生復帰

追加依頼: PC の02もSPと同じ線画・透明度フェードへ統一。iPhone 17 Pro / Safari で03がタップまで再生しないとの報告。

- css/dx.css: 02の線の発光、写真のblur、brightnessの変化を省くルールをPCにも適用。
- js/dx-ai-pers.js: PCも退場中の線画を一時停止し、不要な完成写真フェードを防止。
- js/dx-bimx.js: SPは03が表示され始めたら再生し、is-moving解除まで待たない。muted/playsinlineは維持。再生拒否や予期しないpauseには250/1000/2000msの最大3回の再試行。画面外・別工程・非表示タブ・動きを減らす設定では停止。
- js/dx-steps.js: transitionendが失われても、CSSの切り替え時間+100msでis-movingを解除。切り替え直しで古いタイマーを破棄。

実コードを用いたDOM/media模擬検査52項目、JS構文確認、diff空白検査通過。ローカル390pxでタップなしの03再生（readyState4、再生時刻進行）、1440pxで02の実行中に線・完成写真のfilter:noneを確認。実iPhoneでの再現確認は未実施で、原因は確定していない。Safariの自動再生ポリシーによる拒否を無制限に再試行しない。
