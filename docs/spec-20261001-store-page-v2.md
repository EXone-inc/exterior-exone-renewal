## 1. 背景・目的

支店ページは旧 PC カンプ（`534:628`）と、カンプの無い SP を補間した形で 7 拠点ぶん実装済み（`page-store.php` + `template-parts/store/` + `inc/store-data.php` + `css/store.css` + `js/store-*.js`）。新カンプは旧 PC を整理し直した改訂版で、影・白・罫線の色の統一、句点の削除、DX・WORKS を TOP / DX ページの部品にそろえること、guide による動き（エンドレスロール・浮遊・フェードイン・線画アニメ・アーチ状ロール）の追加、そして**初めての SP カンプ**が入った。

地域で外構を検討している人が、支店ページを開いてから問い合わせるまでの体験をコーポレートサイトの他ページ（TOP・DX・PLANS）と同じ質感にそろえる。あわせて、支店ごとに変わる部分（AREA の店内写真・外観写真・Local Expertise）を支店ごとに差し替えられる形にし、素材が届けば差し替えるだけで済むようにする。

## 2. スコープ

### やること

- 既存の支店ページを**その場で改修**する（URL `/store/<slug>/`・固定ページ・7 拠点データの持ち方・クラス `.p-s*`・トークン `--st-*` は維持。決定 B「進め方」）。PC `612:99` / SP `670:239` の**両方**を忠実再現の対象にする
- 設計メモ §8.1（PC）・§8.4（SP）の差分をすべて反映する
- guide `617:57` の 13 注釈の動き（§7.1）
- 既存部品の再利用: TOP の DX（`template-parts/top/section-dx.php` + `js/dx-slider.js`）、WORKS の DX モード（`template-parts/common/section-works.php` + `js/works-gallery.js` + `js/works-estimate-modal.js`）、PLANS の img list の動き（`js/plans-imglist.js`）、TOP 理念の浮遊（`js/philosophy-diagram.js` の `p-diagram-float`）、線画アニメ（`js/line-draw.js` + `images/top/line_animation.svg`）、下からフェードイン（`js/scroll-reveal.js` の `[data-reveal]`）、FAQ のアコーディオン（`js/store-faq.js`）
- 新規の動き: AREA の店内写真のアーチ状エンドレスロール（PC は弧、SP は直線。決定 A）
- `inc/store-data.php` に、支店ごとに差し替えられる項目（AREA の店内写真・外観写真、Local Expertise の見出し・本文・写真）を足し、7 拠点とも青森の内容を仮置きする（決定 A）
- 新たに必要な画像の取り込み（設計メモ §11。取り込み元は決定事項ファイル冒頭の scratchpad `figma-store-v2/`）
- 不要になったファイル・CSS・画像の整理（`js/store-fv.js`・`js/store-dx.js` ほか）

### やらないこと（範囲外）

- `/store/` 親ページ（一覧）の見た目、他ページ（TOP・DX・PLANS・企業情報）の見た目・動きの変更（決定 B「対象外」）
- CTA の LINE URL・電話番号の実値（`#` のまま）、FAQ の回答文・REVIEWS の口コミ・他支店の素材（仮のまま）
- 他 6 拠点の AREA 店内写真・外観写真・Local Expertise の文言と写真の調達（青森を仮置き。公開前に差し替え）
- PACKAGE / HIGH-END / COLUMN の VIEW MORE の遷移先（旧決定 Q9 の `#` のまま。DX の VIEW MORE は TOP 部品に従う → オープン論点 Q8）
- CPT・タクソノミー・カスタムフィールドの新規追加（管理画面での入力項目は発生しない）
- 画像の最終調達。取り込む画像は **AI 生成プレースホルダを含む差し替え前提の仮画像**
- タブレット専用レイアウト（中間幅は決定 B「中間幅」の補間のみ）
- 実装しないノード: guide の灰色矩形・矢印・支店ラベル（`681:369`〜`681:380`）、SP の重複ノード `641:389`、SP の WORKS モーダル背面キャプチャ `641:422`（背面のぼかしで代替）

### 忠実再現の定義（CLAUDE.md と同一文言）

- **一致必須**: セクション構成・配置・配色・タイポグラフィ・余白感
- **求めない**: px 単位の完全一致

### カンプの不備・表記ゆれの扱い

決定事項ファイル B「カンプの不備（設計メモ §9）」に従う。要点: REVIEWS / CAR SPACE / 「完成・お引き渡し」/ FLOW 03 は 01 と同文のまま / WORKS 本文 18px 統一（PC）。SP の Quality 英字・AREA 帯見出しは PC の文言、「Visible Design」、雪道写真は正位置、見積モーダル「その他」は ¥479,700、「外構」の空白除去、FAQ 質問 2・8 は PC の文言、1〜10px のずれ・不揃いは揃える、行頭行末の半角空白は除去。SERVICE 白パネル・WORKS 見積表パネルには影を付けない（決定 B「白パネルの影」）。トークン外の値は `css/store.css` の `:root` の `--st-*` に追加してから使う（共通トークンは再定義しない）。

### 動きの受け入れ基準の読み方（Evaluator 向け）

- 主検証は `/store/aomori/` の **375px と 1920px**。他 6 拠点（sendai / totsuka / morioka / hachinohe / hirosaki / tokyo）は崩れとデータの出し分けを確認する（決定 C）
- 「動きを減らす設定」は Playwright の `reducedMotion: 'reduce'`、「JS 無効」は `javaScriptEnabled: false` で再現する
- 静的な見た目の AC は、動き（ロール・浮遊・フェードイン・線画・DX のピン留め）の影響を避けたい場合 `reducedMotion: 'reduce'` で開いて確認してよい
- 「〜秒後」はページ読み込み完了またはスクロール操作の完了からの経過時間。速さの判定は ±25% の幅で行う
- 再利用部品の退行確認は、**作業前の状態のスクリーンショット・計測値を S1 開始時に取っておき**、それと比べる（取得は Generator、比較は Evaluator）
