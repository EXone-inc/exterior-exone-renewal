## 8. カンプが定義していないこと（要確認）

実装者がユーザーに確認すべき点。推奨があるものは先頭に置いた。

1. **PC ヘッダー**: 6 画面ともヘッダー無し。FV が 515 高で明るい写真のため、他 FV ページ（`exterior_exone_has_fv_header()` の重ね表示 + 上端グラデ）をそのまま使うと白ロゴが写真に埋もれる可能性 → ①FV に重ねる既存方式 ②通常ヘッダー（黒帯）を上に置き FV を 45〜 から始める、のどちらか。支店モード（`?store=`）時の支店ヘッダー / フッター出し分けも同様
2. **URL とテンプレート**: `/contact/` 固定ページ + `page-contact.php` でよいか。`exterior_exone_contact_item()` の `'#'` をその URL に差し替える。支店ページ・フッター・ドロワーからの導線は既存のまま
3. **支店経由の初期選択**: guide「支店経由の場合は下が選択状態」。`?store=<slug>`（既存の支店モード）を読んで 個人 + その支店 を選択済みにし、方法ボタンまで開いた状態で表示、で合っているか。そのとき初回表示の「1 画面に収める」要件は外れてよいか（guide はそう読める）。URL 直接指定（`/contact/?store=aomori` を共有された場合）も同じ扱いか
4. **店舗の並びと出典**: カンプは 青森 / 弘前 / 八戸 / 盛岡 / 仙台 / 戸塚（北→南）、`inc/store-data.php` は 仙台 / 戸塚 / 盛岡 / 青森 / 八戸 / 弘前（フッター STORE もこの順）。CONTACT だけカンプ順にするか、データ順に揃えるか、データの順を変えるか（変えるとフッターも変わる）
5. **電話ブロックの文言の出典**: 「10:00〜18:00 （定休日：土日祝）」はカンプの書式、データは `hours: AM10:00～PM18:00` / `closed: 土・日・祝`（戸塚は 火・水・祝）。カンプ書式に整形して出すか、データの書式のままか。PC の番号を `tel:` リンクにするか。「青森支店　電話番号」の全角スペースは実装でも入れるか
6. **アイコン**: ①LINE の白（反転）アイコンがカンプに無い（画像素材フレームは題名だけ）→ 支給を待つか、黒版を反転して作るか ②メール / 電話の白アイコン PNG は縁が粗い AI 生成 → SVG 化 or CSS `filter: invert(1)` で黒版から作ってよいか ③3 種の視覚サイズ（41×24 / 41×39 / 38×38）を揃えるか
7. **フォームの送信先と処理**: ①プラグイン無し（Contact Form 7 等を入れるか、自前の `admin-post` / `wp_mail` ハンドラか）②**受信先**: 個人フォームは支店ごとに受信メールを分けるか（guide も「？」）、法人フォームは本部宛か。支店の受信アドレスはデータに無い（store-data に `email` 相当のキー無し）③送信後に支店名・方法を hidden で送るか ④スパム対策（reCAPTCHA / honeypot）⑤個人情報の同意チェックボックス・プライバシーポリシーへのリンク（カンプに無い）
8. **確認画面・完了画面**: ボタンが「送信内容を確認する」なので確認画面がある前提だが、確認画面・送信完了（サンクス）画面・送信エラー画面のカンプは無い。①確認画面をページ内で入力欄を読み取り専用にして出す ②別ページ `/contact/confirm/` `/contact/thanks/` ③確認を省いて即送信、のどれか
9. **バリデーション**: 必須 / 任意の表示（カンプにマーク無し）、未入力・形式エラー時の見た目と文言、郵便番号の桁数チェック（「ハイフンなし」= 7 桁数字）、エラー時のスクロール位置
10. **入力欄の状態**: プレースホルダ文言、フォーカス時の枠色、autocomplete 属性、テキストエリアのリサイズ可否、メールアドレスの type=email / 電話番号の type=tel
11. **選択の切り替え挙動**: ①個人 ↔ 法人を入力途中で切り替えたときに入力内容を保持するか破棄するか ②支店を切り替えたときに方法の選択を解除するか ③方法を切り替えたとき（メール → 電話）にフォームを隠すか ④同じボタンをもう一度押したら解除するか ⑤出現ブロックへの自動スクロール（PC は 1 画面に全部収まらないので、支店選択後に方法ボタンが画面外に出る）⑥出現アニメーション（フェード / スライド / 無し。カンプは静止画のみ）
12. **末尾余白**: フォーム画面 160 / 電話画面 314 / 途中画面 320 / デフォルト 152 で不揃い → 160 に統一でよいか。フッターは既存 footer.php でよいか
13. **ホバーの詳細**: 「色反転」はボタン全体（枠 → 塗り、文字 → 白、アイコン → 白）でよいか。送信ボタン・入力欄・電話番号のホバーは未定義。タッチ端末でのホバー残り
14. **LINE リンク先**: 青森と弘前の `line_url` が同じ（`https://lin.ee/Tfvjo0k`）。支店専用リンクという guide に対して、これでよいか
15. **SP の法人フォーム**: SP カンプに無い。個人フォームの組み（ラベル上 + 欄下、ピッチ 64）で 7 行に補間してよいか
16. **「CONTACT」ゴースト文字の重ね順**: 写真の上に #d9d9d9 100% で置く（カンプどおり）か、写真より背面に回して地の上だけ見せるか。PC で写真帯の下 68px だけ地と同化して読めない状態になる
