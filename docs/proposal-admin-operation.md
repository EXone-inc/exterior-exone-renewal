# 提案事例・デザインテイストの管理

本番の EXone Renewal では、WordPress 左メニューの「提案事例」から操作する。

| メニュー | 管理する内容 |
| --- | --- |
| 施工事例（旧テーマ） | 従来の本番サイト用の施工事例 |
| 提案事例 | 新テーマで表示する事例。移行済みの12件と、今後追加する提案事例 |
| 提案事例 → デザインテイスト | 新テーマの事例に指定するテイストと、公開一覧の絞り込み候補 |

「施工事例（新テーマ）」は今後の追加対象で、今回の機能には含まない。

## 提案事例を登録・変更する

1. 「提案事例」から「新規追加」または対象行の「編集」を開く。
2. タイトル、説明、メイン画像・外観写真・3Dパース・図面、デザインテイストを入力する。
3. トップページにも掲載する場合は、掲載チェックを入れる。
4. 公開状態を選び「保存する」を押す。新規の初期状態は下書き。

公開した事例は既存の `/works/` に表示する。トップページは、公開中かつ掲載チェックのある事例から新しい順に最大5件を表示する。既存事例のURLと公開日時は、この画面の編集では変わらない。

「画像を解除」はその事例から画像を外す操作で、メディアライブラリの画像ファイルは削除しない。

事例の削除は「ゴミ箱へ移動」。ゴミ箱から「元に戻す」と、移動前の公開／下書き状態に戻る。公開事例を復元すると掲載も再開する。

## 提案事例の表示順を変える

1. 「提案事例一覧」の「すべて」を開く。
2. 左端のハンドルをドラッグするか、上下ボタンで行を移動する。
3. 「表示順を保存」を押す。保存後に画面が再読込される。

保存した順番は公開一覧と詳細ページ内の事例一覧に共通で反映される。保存するまでは公開側に反映されない。新規追加した事例は、保存済み事例の後ろに追加される。TOP掲載の選択・日付順は従来どおり。

「公開」「下書き」「ゴミ箱」では並べ替えを保存できない。「すべて」に戻って操作する。別の画面で先に変更された場合や保存結果を確認できない場合は、再読込して現在の順番を確認する。

通常ローカルでは「提案事例 → 表示順」で同じ操作ができる。

## デザインテイストを管理する

「提案事例 → デザインテイスト」で名称の追加・変更・削除ができる。事例ごとに1つのテイストを指定できる。

使用中のテイストを削除しても、事例本文や画像は残る。そのテイストの指定が外れ、公開一覧の絞り込み候補から消える。削除前に表示される利用事例数には、下書きとゴミ箱内の事例も含む。

別の管理画面で先に変更された場合は、保存を停止して画面を開き直す案内が出る。一覧で最新状態を確認してから編集し直す。

## 通常ローカルとの違い

通常ローカルでは、従来の「提案事例」と標準のデザインテイスト管理画面を使う。本番では旧テーマ用データを保持するため、新テーマ専用画面を使う。管理画面の配置は異なるが、事例の入力項目は同じ。

旧テーマへ戻すと、この新テーマ専用メニューは表示されなくなる。新テーマ用データは保存したまま残る。
