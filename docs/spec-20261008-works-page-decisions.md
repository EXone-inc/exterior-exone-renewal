## 3. 既定（呼び出し側が決めた。変えたい場合はユーザーに確認）

### URL・テンプレート・データ
- 一覧 `/works/`（投稿タイプ `works` のアーカイブ。既存のリライトどおり）、詳細 `/works/<投稿名>/`。テンプレートは `archive-works.php` / `single-works.php`（`index.php` の仮表示を置き換える）
- 一覧は `pre_get_posts` で `works` アーカイブだけ `posts_per_page = -1`（全件）・日付の新しい順。ページ送りなし
- 投稿のフィールド（既存。`inc/meta-boxes.php`）: タイトル = 詳細の和文見出し、説明文（`post_content`、改行つきテキスト）= 詳細の本文、ギャラリー（`_exterior_exone_works_gallery`、添付 ID の並び）= 写真、所在地（`_exterior_exone_works_area`）= 今回は表示しない、TOP 掲載フラグ = 既存どおり
- **メタボックスの案内文だけ更新**: ギャラリーの説明に「1 枚目 = メイン（一覧・詳細の左ページ）/ 2 枚目 = 外観写真 / 3 枚目 = 3Dパース / 4 枚目 = 図面。4 枚登録する」と書く。入力欄は増やさない
- デザインテイスト = タクソノミー `works_package`（DB の 6 ターム: クールモダン / アーバンモダン / シンプルモダン / ラスティックモダン / スタイリッシュモダン / ナチュラルモダン）。ボタンの文言はタームの名前（カンプの「ナチュラル」ではなく DB の「ナチュラルモダン」）。並びはカンプの順（クールモダン → アーバンモダン → シンプルモダン → ラスティックモダン → スタイリッシュモダン → ナチュラルモダン）をコードの並び順表で決め、表に無いタームは末尾に名前順
- 詳細の英字見出し（「Cool Modern」）= テイストの英名。コードの対応表（クールモダン → Cool Modern / アーバンモダン → Urban Modern / シンプルモダン → Simple Modern / ラスティックモダン → Rustic Modern / スタイリッシュモダン → Stylish Modern / ナチュラルモダン → Natural Modern）。表に無いタームは名前をそのまま。テイスト未設定の投稿は英字を出さない
- 投稿に写真が 4 枚無いとき: ある枚数で動かす（2 枚以上ならめくれる。1 枚なら静止。キャプションは位置で固定したまま）。写真が 0 枚の投稿は一覧・詳細ともグレーのプレースホルダ

### 一覧ページ
- 構成: FV（画像 + 「WORKS」+「理想の暮らしを描く、外構のご提案事例」。PLANS / ハイエンドの FV と同じ組版）→ 見出し「Filter by Design Style / デザインテイストで絞り込む」→ 絞り込みボタン 6 個 → 写真グリッド（PC 3 列・SP 2 列）→ COLUMN
- 写真カード = 投稿のギャラリー 1 枚目（cover）。押すと詳細ページの**1 セクション目**（FV の次の見出しの位置。アンカー `#works-detail`）へ（guide「遷移先は FV ではなく 1 セクション目から」）。文字は出さない（カンプどおり）
- 絞り込み: 単一選択のトグル（`aria-pressed`）。アクティブは色反転（白地 + 黒文字。guide）。絞り込みはページ内の JS で表示 / 非表示（短いフェード）。**0 件のときは「該当する事例はありません」を出す**（カンプに無い状態。呼び出し側既定。報告で確認）。JS 無効時は全件表示でボタンは効かない
- ホバー: 既存の作法（`a:hover` 不透明度 0.7、ボタンは色反転の予告なし）

### 詳細ページ
- 構成: FV（一覧と同じ画像・文言）→ 見出し（英字 = テイスト英名、和文 = 投稿タイトル。`#works-detail`）→ パンフレット（左ページ 1172 + 右の見切れ 472、ハイエンドと同じめくり・自動送り・進捗の下線）→ 名前（英字大 = テイスト英名「COOL MODERN」）+ サムネ 3 枚 + キャプション + 下線 → 本文 → 一覧ブロック（絞り込み + グリッド。一覧と同じ部品）→ COLUMN
- パンフレットの写真 = ギャラリーの 1〜4 枚目。**左ページ = 現在 N、右ページ = N+1、サムネ = N+1 / N+2 / N+3**（循環。guide の並び順の図）。サムネまたは右ページを押すと、その写真が左ページに来るように 1 回めくれる（押した写真が目標。途中の写真は飛ばす）。左ページを押すと次へ（ハイエンドと同じ）。自動送り 5 秒・めくり 1.2 秒・進捗の下線はハイエンドと同じ値
- キャプション: サムネの下に、その写真の位置に応じて「外観写真 / 3Dパース / 図面」（1 枚目 = メインにはキャプション無し。サムネに 1 枚目が回ってきたときは空欄）
- 「パンフレット直下のコンテンツ（名前・サムネ・キャプション・下線・本文）」は右からフェードイン（`[data-reveal="right"]`）し、めくれる紙より前面（guide）
- 3Dパースは静止画（model-viewer 等は使わない）
- めくりの部品はハイエンドの Gallery（`js/highend-gallery.js`・`.p-hepgal*`・`template-parts/highend/section-gallery.php`）を**共通部品に切り出して両ページで使う**（本・ページ・めくれる紙・短冊・落ち影・当たり判定・進捗）。タブとキャプションは任意にする。**ハイエンドページの見た目と動きは変えない**（回帰で確認）

### 共通
- SP の一覧は、SP 詳細カンプ（`836:37`）からパンフレット部分を除いた形（FV → 絞り込み → グリッド 2 列 → COLUMN）で補間
- COLUMN は支店ページの部品（`template-parts/store/section-column.php` + `.p-scolumn`）を流用。支店依存を外し、CSS（COLUMN と見出し 3 点セット + 必要なトークン）は共通 CSS に切り出して支店ページと WORKS の両方で読む。**支店ページの見た目は変えない**（回帰で確認）
  - コーポレート（`?store=` なし）の文言: 見出し「外構づくりに役立つ情報」、リード「外構費用の考え方やカーポートの選び方、目隠しフェンス、庭づくりなど、外構工事を検討している方に役立つ情報を発信します。」+ 2 行目は支店と同じ。VIEW MORE は PC のみ（SP のカンプに無い）
  - 支店モード（`?store=<slug>`）のとき: 支店ページと同じく「<地域>の外構づくりに役立つ情報」「…<地域>で外構工事を…」
- 支店モード: 一覧・詳細とも `?store=` で支店モードになる（既存）。カード・絞り込み・VIEW MORE・COLUMN のリンクは `exterior_exone_store_link()` 経由
- ヘッダー: PC は既存の半透明ヘッダーを FV に重ねる（`exterior_exone_has_fv_header()` に一覧・詳細を追加）。支店モードは黒い追従ヘッダー（既存）
- 既存の `css/works.css`（支店 / DX の 1 事例部品 `.p-cworks`）とは別に、ページ用 CSS は `css/works-page.css`（`--wkp-*`、PC `--wkp-vu` / SP `--wkp-su` の比例方式）
- 画像: FV は `images/works/`（保存済み）。投稿の写真は添付（`wp_get_attachment_image`、サイズ `large` 以上）
- サンプルデータ（ローカルのみ）: WP-CLI で `images/works/` のグリッド 12 枚を `media import` し、既存 6 件 + 新規 6 件の投稿に 1 枚目として割り当て、2〜4 枚目は詳細カンプの外観写真 / 3Dパース / 図面を共通で入れる。テイストは 6 種に 2 件ずつ。タイトル・本文はカンプの文言ベースの仮文。TOP 掲載フラグは既存どおり
