## 動きを減らす設定（iOS「視差効果を減らす」）と低電力モードへの対応（2026-09-25 ユーザー決定）

方針: 止めるのは「勝手に動くもの」だけにして、内容と操作は残す。

| 箇所 | 動きを減らす設定がオンのとき |
|---|---|
| Exterior Explorer | 画面固定はそのまま、映像の代わりに章ごとの静止画（`images/dx/explorer/{pc,sp}-*.webp`）を 0.8 秒のフェードで切り替える（`data-mode="stills"`）。映像を読めなかったとき（ステージングの 8MB 除外など）も同じ表示。JS が動かないときだけ静止画を縦に並べる |
| ステップ 03 の 3D | 3D は表示したまま自動回転を止め、ドラッグで回せる（`.is-model-interactive`）。通常時は自動回転のみで操作不可 |
| ステップ切り替え・WORKS の 3D・装飾アニメーション | 従来どおり（切り替えは流さない / 自分で操作するものはそのまま / 装飾は止めて完成形） |

低電力モード: iOS は画面に触れるまで動画データを読み込まないため、Exterior Explorer は最初のタッチで再生 → 即停止して読み込みを始めさせる（`armUnlock`。TOP の FV と同じ仕組み）。

## 前提（支店ページから引き継ぐ運用）

- カンプは PC（436:95）と SP（439:1070 → 本体 439:752）の **2 幅が揃っている**。SP は補間ではなくカンプどおりに組む
- 固定ページ + `page-dx.php` + `template-parts/dx/section-*.php` + `inc/dx-data.php` + `css/dx.css`（`--dx-*` は TOP の DX セクションが既に使っているため、ページ用プレフィックスは **`--dxp-`** とする）+ 必要な `js/dx-*.js`
- 線画・アイコン・写真は「Figma の描画部分をカンプ枠の比率に合わせる」（枠固定 + object-fit）
- リンク先未定は `#`。文言の誤記は修正して実装し、判断が要るものは仕様書のオープン論点に残す
- generator は **1 スプリントごとに新しい agent** を起こす（コンテキスト肥大で停止した前例あり）
- **縦長の画面で固定した工程（`.p-dxsteps__stage`）の内容が上に寄っていた（2026-10-10 ユーザー指摘。iPad Pro 13 縦 1032×1376）**: PC の `--dxp-vu` は幅で決まるため、画面が縦長だと 1 画面の下が空く。`.is-enhanced .p-dxstep { justify-content: center; padding-bottom: var(--dxp-step-pin-slack) }`（slack = 61vu = 1920×1080 で内容の下端 → フローバーの余り）で余りを上下に等分し、内容を縦中央に。1920×1080 では位置が変わらない（上 77 / 下 61）。SP は既に中央寄せ
