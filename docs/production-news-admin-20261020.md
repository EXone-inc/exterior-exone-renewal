## 操作方法

新テーマを有効にしたときだけ、WordPress管理画面の左メニューに「お知らせ（新テーマ）」が表示される。管理者が操作できる。

1. **登録**：「新規追加」を開き、タイトル・本文・画像・表示日を入力する。タイトルは必須。公開状態を選び「保存する」を押す。初期状態は下書き。
2. **変更**：一覧の「編集」を開き、内容を変更して保存する。
3. **削除**：一覧の「ゴミ箱へ移動」を押す。公開されなくなるが、内容は保持される。
4. **復元**：「ゴミ箱」から「元に戻す」を押す。ゴミ箱へ移動する前の状態に戻るため、公開済みだった記事は再掲載される。

公開にした記事は、新テーマのトップページとお知らせ一覧へ反映される。旧テーマへ戻したときは、従来どおり旧テーマの内容を表示する。

本文は文章と改行を入力する欄で、HTML編集には対応しない。表示日は今日以前の日付を使う。画像を外してもメディアライブラリの画像自体は削除されない。

同じ記事を二つの画面で編集し、先に別画面から保存した場合は、古い画面からの上書きを止める。一覧から最新の内容を開き直して編集する。
