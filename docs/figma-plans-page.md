## 6. 要確認事項

### 用途・仕様が決まらない点
1. **PLAN select クリック後の画面構成** — guide ①②③ は「クリックした側の背景が丸く広がり、プラン名が中央へ移動し、プラン名の下が各プランの項目に変わる」、613:1360 は「以降2つが共通セクション」。PACKAGE と HIGH-END は (a) どちらか一方だけを表示して plan btn のタブで切り替える（その下に共通 2 セクション）のか、(b) カンプどおり縦に 2 つとも並べてその位置へスクロールするのか。プラン名の移動先 y も PACKAGE +270（ヘッダー下）/ HIGH-END +160 で違う
2. **PC の header と plan btn の扱い** — FV・PLAN select にはヘッダーが描かれず、PACKAGE PLAN 上端にだけある。ヘッダーは FV から常時表示か、プラン選択後に現れるのか。タブ（パッケージ / ハイエンド）は追従（固定）か、その場に置くだけか。HIGH-END 表示時のタブ（選択が入れ替わった状態）のカンプが無い
3. **「現コーポレートサイトFVのような広がり方」の参照先** — 現行の本番サイト exterior-exone.com の FV か、リニューアル TOP の FV か。速度・イージング・「半分の領域で」の広がりの起点（クリック位置 / 半分の中心）
4. **SP の PLAN select の動き** — SP 用の注釈なし。SP は各列に VIEW MORE がある。タップ対象は列全体かボタンのみか、PC と同じ「丸く広がる」切り替えをするか、該当セクションへスクロールするだけか。SP にはタブが無いので切り替え後に他方のプランへ移る手段も未定
5. **style list の選択中カードの見た目** — カンプではカード 01 が選択中のはずだが 02・03 と見た目が同じ。選択中・ホバーの表現（TOP は選択中のカードを持ち上げる）
6. **style list のテイスト数と各テイストの内容** — カンプは 01〜04（04 は見切れ、03 と 04 は同じ画像）。TOP は 5 テイスト。何件か、各テイストの英名（「SIMPLE MODERN」に当たるもの）・説明文・画像はどれか。SP の「スライダー」の操作（スワイプ / 矢印 / ドット）もカンプ無し
7. **img list の「エンドレスで自動スクロール」** — 速度・方向・ホバー時に止めるか。SP（3 枚見え）でも同じ動きか
8. **VIEW MORE のリンク先** — PACKAGE 下（586:481）/ HIGH-END 下（586:402）/ SP の PLAN select 2 個・各セクション下 2 個
9. **designer plan / top designer plan のフェードイン** — 動かすのはブロック全体か、写真と文字を別々にか。移動量・速度・きっかけ（画面に入った時点か）。SP でも左右から入れるか
