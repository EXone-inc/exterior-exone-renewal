## 3. 既定（呼び出し側が決めた。変えたい場合はユーザーに確認）

### ページ・導線
- 固定ページ: 親 `plans`（既存）の子、slug `high-end`、テンプレート `page-high-end.php`（slug で自動対応。`template_include` 不要）。WP-CLI で作成する（DB 変更。公開状態）
- `exterior_exone_has_fv_header()` に追加し、PC は既存の半透明ヘッダーを FV に重ねる（カンプに PC ヘッダーは描かれていないが、他ページと同じ扱い）。支店モードでは黒い 113 のヘッダーになる（既存の仕組み）
- リンク（すべて `exterior_exone_store_link()` 経由で支店モードの `?store=` を引き継ぐ）
  - TOP の PLANS セクションのハイエンド VIEW MORE（`template-parts/top/section-plans.php` の `#`）→ `/plans/high-end/`
  - PLANS ページ HIGH-END の VIEW MORE（`inc/plans-data.php` の `'more' => '#'`）→ `/plans/high-end/`
  - 支店ページ PLANS のハイエンド VIEW MORE（`inc/store-data.php` の `'more' => '#'`）→ `/plans/high-end/`
  - 「DX体験を見る」→ `/dx/`
  - CONTACT の「ハイエンドプランについて相談する」→ **未設定（`#`）のまま**（お問い合わせページが無い。公開前チェックリスト）
- ヘッダー・フッターは既存の共通部品（支店モードの出し分けも既存どおり）

### FV の演出（guide 713:213 / 713:218）
- `page-company.php` と同じく FV と次の要素を `<div class="l-pin">` で包み、`js/fv-mask.js` の進捗（`--fv-mask-progress` 0 → 1）を使う。固定区間は**画面 2 つ分**（カンプの animation img + mask animation）
  - 進捗 0 → 0.5: 夕景（`pc-fv-bg-evening-713-35.jpg`）の上に夜景（`pc-fv-bg-night-713-39.jpg`）をクロスフェード（夜景の opacity を 0 → 1）。FV のコピー「HIGH-END DESIGN / 唯一無二の一邸、あなただけの特別を」はこの間に消える（企業情報と同じ）
  - 進捗 0.5 → 1: 黒 50% の暗幕（カンプ 713:118）を 0 → 1、続いて「HIGH-END DESIGN（64px）+ 本文 5 行 + ロゴ」を下からフェードイン。PC は下端 443px のグラデ（`pc-mask-gradation-713-119.svg`）で次のセクションの地 #1a1a1a に溶かす（SP はカンプどおり無し）
  - 進捗 1 以降は通常のスクロールで section 1 が下から出てくる
- 動きを減らす設定・JS 無効: 固定せず、夜景 + 暗幕 + コピーの完成状態を 1 画面で出す（企業情報と同じ扱い）
- `fv-mask.js` は 1 ページ 1 つの `.l-pin` しか扱わないが、このページで使うのは FV だけなので問題ない。暗幕の色は既存トークン `--philo-overlay` ではなくカンプの黒 50% をページのトークンで持つ（`fv-mask.js` を変えずに、ページ CSS 側で `::after` の地を上書き）

### Design Philosophy（section 1）
- 写真帯は `js/plans-imglist.js` のエンドレスロール（`[data-plp-imglist]`）。速さは PLANS・支店と同じ `--plp-imglist-screen-time` 40s

- 文言はカンプの PC を正とする。SP のコピペ残り（03・04 の見出しが 01・02 と同じ、02 の読点）は PC に合わせる

### Design Plans（section 3）
- 文言・価格・写真は PLANS ページ HIGH-END のプランデータと同じ（`exterior_exone_plans_highend()` を流用。写真も `images/plans/` のもの）。カード 2 の英名はカンプ PC の「DESIGNER PLAN」ではなく **TOP DESIGNER PLAN**（SP・PLANS と同じ。カンプの誤り）

## 7. 追加指示（2026-10-05、S3 着手後）

- **パンフレットのめくりは、ユーザー支給の参考コード `docs/reference-20261005-page-animation.html` の方式で作る**（左ページを細い短冊 48 本に分け、綴じ目から外縁へ向けて角度を変えながら回し、紙が「しなる」ように見せる。短冊ごとの表 / 裏と明暗、落ち影、ResizeObserver で再描画）。仕様書 §F-07 の「1 枚の板を rotateY」より本方式を優先する
- **参考コードで一瞬入る縦の線は出さない**。原因の見立て: 短冊どうしの重なり（overlap 1.25px）の上に半透明の黒（`.strip-light`）が二重に掛かって濃い線になる／回転した短冊の端のアンチエイリアスの隙間。対策: 明暗は重なり部分に二重に掛からない形にする（重なり幅を除いて掛ける、または短冊の中身側に `filter: brightness()` で掛ける）、重なりは 2〜3px 以上、位置と幅は整数に丸める。めくりの途中（進捗 0.3 / 0.5 / 0.7）のスクリーンショットで、周期的な縦線が無いことを画素で確かめる
- めくりの所要時間 1.2 秒（決定 §2）は維持。イージングは参考コードの smootherstep（`p³(p(6p−15)+10)`）でよい
- 参考コードの「自動再生 ON/OFF ボタン」「ページを戻す」ボタンは不要。操作はタブ・ページ画像のクリック・自動送り（決定 §3）
