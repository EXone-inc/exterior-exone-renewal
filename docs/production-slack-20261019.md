## 反映後の操作方法

新テーマを有効にすると、WordPress の「外観 → 新テーマの Slack 通知」に、お問い合わせ（個人・法人）と採用の設定が表示される。

通知先を変更するときだけ URL を入力して保存する。空欄で保存した場合は現在の通知先を保持する。通知を止める場合は対象の「Slackに通知する」を外して保存する。保存時のテスト送信は行わず、登録済みの URL は画面へ再表示しない。

通常のメール送信が成功した後に Slack 通知を試みる。画面の「設定済み」は通知先が保存されていることを示し、実際の受信確認を示すものではない。

## ユーザーによる受信確認

1. 新テーマへ手動で切り替える。
2. 個人・法人・採用の各フォームから、テストと分かる内容を送信する。
3. 通常メールと、指定した Slack 側の通知先で受信を確認する。自動返信については各フォームの既存設定に従う。

実際の送信試験はメールと Slack へ通知を発生させる。今回の隔離検証では外部への HTTP・メールを遮断し、実受信とは区別して記録する。
